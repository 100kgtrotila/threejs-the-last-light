# Gothic Island Environment and Spatial Validation

This user-directed environment phase precedes the movement work in the original plan. Keep the existing anchors, single renderer, camera presets, and static inspection flow.

1. Extend the authored layout with structure footprints, reserved routes and artifact clearings. Add deterministic prop generation and exact circle/box/capsule placement tests before decoration.
2. Build continuous terrain and coastal cliffs, a static dark ocean, Gothic lighthouse masonry, cemetery graves and mausoleums, three empty artifact sites, and seeded natural props. Ground each entity using one terrain sampler.
3. Validate updated world-space bounds, then precise authored colliders; distinguish support contact and architectural joints from conflicts between entities. Audit finite positions/normals, triangle area, and duplicate triangles. Display exclusion zones, collider bounds, and problematic placements in debug mode.
4. Run the full test suite, TypeScript check, production build, and browser inspection at fixed viewpoints and viewport sizes. Fix demonstrated defects and report actual results. No controls, gameplay, complex weather, commits, or pushes are part of this phase.
